# Course PCAP

[한국어](../../../../../../labs/lab01/part5_wpa2/data/wpa2/PLACE_PCAP_HERE.md) | [English](PLACE_PCAP_HERE.md)

Code and data are shared in the [original directory](../../../../../../labs/lab01/part5_wpa2/data/wpa2/). Run all commands from the original exercise directory in the course container.

`lab01-handshake.pcap` is the instructor-approved capture used by Part 5.
Students must use it only for the documented offline exercise. Do not replace it
with captured or downloaded third-party traffic.

Students inspect its protocol fields manually with Wireshark or TShark. It is a
separate dataset from `../wpa2_capture.json`, which supports the Python
calculation exercise.

The SSID and endpoint MAC addresses in this copy are fictional course
identifiers. They do not identify the equipment used to create the original
authorized fixture.

`lab01-pcap-wordlist.txt` is a deliberately tiny classroom candidate list. It
is not intended for use with any other file or system.
