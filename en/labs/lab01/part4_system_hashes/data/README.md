Code and data are shared in the [original directory](../../../../../labs/lab01/part4_system_hashes/data/). Run all commands from the original exercise directory in the course container.

All records and passwords represented here are fictional course fixtures.

- `linux_hashes.txt`: synthetic shadow-style record.
- `lab01-small.txt`: bounded wordlist for the optional local John exercise.
- `rainbow_lab_config.json`: current bounded password-space and chain
  parameters.
- `rainbow_password_database.csv`: fictional accounts with unsalted SHA-256
  targets for the current table comparison.
- `rainbow_config.json`, `rainbow_targets.txt`, and `salted_targets.json`:
  optional additional public fixtures for independent table experiments.
