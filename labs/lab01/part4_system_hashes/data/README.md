# Part 4 데이터

[한국어](README.md) | [English](../../../../en/labs/lab01/part4_system_hashes/data/README.md)

여기에 있는 모든 레코드와 비밀번호는 가상의 수업용 데이터입니다.

- `linux_hashes.txt`: 합성 shadow 형식 레코드.
- `lab01-small.txt`: 선택 사항인 로컬 John 실습용 제한된 단어 목록.
- `rainbow_lab_config.json`: 현재 사용하는 제한된 비밀번호 공간과 체인 매개변수.
- `rainbow_password_database.csv`: 현재 테이블 비교를 위한 가상 계정과 무솔트 SHA-256 대상 해시.
- `rainbow_config.json`, `rainbow_targets.txt`, `salted_targets.json`:
  독립적인 테이블 실험에 선택적으로 사용하는 추가 공개 데이터.
