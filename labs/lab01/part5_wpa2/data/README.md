# Part 5 데이터

[한국어](README.md) | [English](../../../../en/labs/lab01/part5_wpa2/data/README.md)

이 디렉토리의 모든 파일은 실습을 위해 의도적으로 만들었으며 사용이 허가된 수업용 데이터입니다.

- `wpa2_capture.json`: 합성 WPA2 계산용 메타데이터. PCAP이 아니며 아래의 수업용 캡처와 별개입니다.
- `wpa2_passwords.txt`: 합성 계산용 데이터에 사용하는 제한된 후보 목록.
- `wpa2/lab01-handshake.pcap`: Wireshark 또는 TShark 수동 분석을 위해 강사가 승인한 802.11/EAPOL 캡처.
- `wpa2/lab01-pcap-wordlist.txt`: 해당 PCAP에만 사용하는 제한된 후보 목록.

이 파일들을 직접 캡처하거나 다운로드한 제3자 트래픽으로 대체하지 마세요.
어느 단어 목록도 다른 네트워크에 사용하지 마세요.
