# 수업용 PCAP

[한국어](PLACE_PCAP_HERE.md) | [English](../../../../../en/labs/lab01/part5_wpa2/data/wpa2/PLACE_PCAP_HERE.md)

`lab01-handshake.pcap`은 Part 5에서 사용하는 강사 승인 캡처입니다.
학생은 문서에 안내된 오프라인 실습에만 이 파일을 사용해야 합니다.
직접 캡처하거나 다운로드한 제3자 트래픽으로 대체하지 마세요.

학생은 Wireshark 또는 TShark로 프로토콜 필드를 직접 살펴봅니다.
이 파일은 Python 계산 실습에 사용하는 `../wpa2_capture.json`과 별도의 데이터셋입니다.

이 사본의 SSID와 단말 MAC 주소는 가상의 수업용 식별자입니다.
원본의 허가된 실습용 캡처를 생성한 장비를 식별하지 않습니다.

`lab01-pcap-wordlist.txt`는 의도적으로 작게 만든 수업용 후보 목록입니다.
다른 파일이나 시스템에 사용하기 위한 목록이 아닙니다.
